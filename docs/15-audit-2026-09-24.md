## 2 · Blockers — fix before a client walks through it

1. **Worker shift screen has no shift or event data (verified, live).** `apps/staff/app/shifts/[id]/data.ts`
   embeds `shift_requirements` and `events` through the booking; the staff role has no
   read policy on either. As Tom Reid on the live DB: 3 bookings visible, 0 shifts, 0 events.
   The check-in/out screen renders with no times, venue or role. Fix: an owner-rights
   `staff_shift_detail_v` (or definer RPC) scoped to the caller's bookings, like `staff_bookings`.
2. **Client Portal header never shows the company name (verified, live).**
   `apps/client/app/client/layout.tsx:50` reads `clients`; the client role has no policy there
   (correctly, per ADR-0004). Read the name through a `client_*` view instead.
3. **Open redirect after sign-in, all three apps (verified).** `apps/*/app/login/actions.ts:41`
   accepts any `next` starting with `/`, so `//evil.example` and `/\evil.example` leave the site.
   `apps/staff/app/auth/callback/route.ts` blocks `//` but not `/\`. Check
   `new URL(next, origin).origin === origin`.
4. **Event board: no Potential pool, no manual Invite, no auto-assign switch (verified).**
   `RoleBoard.tsx:216` shows placeholder text "The ranked pool arrives with the auto-assign
   engine". §3.3/§3.4 require a ranked, searchable pool with score hover, manual invite, and
   an on/off switch at event and role level. `auto_assign_candidates` exists in the DB and is
   never called from the office.
5. **Duplicate event does not exist (verified).** The Shift Builder tells managers to use
   "Duplicate on the event board" (`ShiftBuilder.tsx:217, 545`); §3.2 makes it the only way
   to build multi-day events.
6. **Shift screen state gaps (§10.4).**
   - A cancelled (N12) or withdrawn (N10b) booking opens the live screen with a Check-in button, not the static message. `staticScreenCase` is already in `packages/domain/src/staff.ts` but nothing calls it.
   - The page skips `StaffShell`, so the §10.1 app lock is not applied on a deep link.
   - The page draws Documents as a disabled "soon" tab (verified, `page.tsx:19-24`).
   - Check-out does nothing without a GPS fix (verified, `ShiftScreen.tsx:266`). §5.1 says check-out works from anywhere, using the last on-site fix.

## 3 · Major — scope behaviour missing or partial

- **N6 / N7 confirm reminders are never queued (verified).** Templates exist, but no sender exists. Workers are released at 12:05 without the day-before reminder.
- **Same-day escalation ignores the 3-mile radius (verified).** `escalation_radius_miles` is editable on `/settings` but nothing reads it.
- **`/offline` promises an offline check-in queue that does not exist (verified).** There is no IndexedDB or background sync. Either build it or change the copy, because a worker who trusts it becomes a No-show.
- **Bank details can be written directly through PostgREST.** The `staff_self_bank_*` policies bypass `staff_save_bank()`, so there is no E5 to payroll and no validation.
- **Back Office has no Forgot password,** although the wireframe has one.
- **Unavailable list on the board labels every cancellation "self-cancelled".** It ignores `cancel_cause`, and never computes blocked, booked-elsewhere or hours-limit.
- **Compliance menu counter (§4.1) is not rendered.**
- **Self-cancel email to admin@ (§9.12) has no code and no sender.**
- **Staff profile (§9.6):**
  - no document download;
  - the conviction declaration is not in the Documents list with Verify/Reject;
  - the Shifts tab has no detail window or Resolve.
- **Office photos never display.** The monitor passes a private Storage path to `<img>`; the directory, profile and qualified-staff lists pass no `src`.
- **gov.uk share-code check (§2.3/§2.6) is not built.** ADR-0002 is still Proposed; the office types the date (ADR-0018).
- **Old-system import (Appendix B5/B6) is not built.**
- **Background location (BG-06) runs in the foreground only** (ADR-0001 limitation; no native shell).
