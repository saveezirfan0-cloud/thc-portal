0 · Modes and stylesUse the switch in the top bar. Theme follows the device by default; both axes are tokens on the root element, so every screen supports all four combinations (docs/09-visual-direction.md, ADR-0003).

Style · Warm (proposed default)

Rounded corners, Plus Jakarta Sans, bold body-face labels, thumb-sized buttons, rounded active nav. Built for an 18–30 hospitality workforce and a busy office. Same palette, same components, same rules.

Style · Scope §1.6 (literal)

Deep navy, zero radius, Space Grotesk / Inter / IBM Plex Mono labels, cyan left-bar nav, square avatars — exactly as written in the Scope of Work and the approved design pack.

Theme · Dark

Navy ground #04080F, panels #0B1220. The brand palette as specified.

Theme · Light

Warm off-white #F6F4EF, white panels, navy ink #141A2C. Cyan stays for fills; text and borders use the deeper teal ink #0B8A99 for contrast.
