Behaviour notes. 5/11 the induction deck is THC's own file shown as-is in the built-in viewer (no native redraw, §10.3); Continue unlocks on the last slide. 6/11 the quiz is available only once every step-4 document is verified (§2.9 gate); multiple choice, pass mark 80%, up to 3 attempts; the third failure moves the candidate to rejected (§2.12) and replaces the wizard with the terminal screen whose copy is identical to email E4 (§10.1 case 3, §8). 7/11 HMRC New Starter Checklist (§2.8): three sequential Yes/No questions — Q2 only if Q1 = No, Q3 only if Q1 = No and Q2 = No — from which the system derives statement A/B/C and the matching tax code for the New Starter report (§9.9); the worker never sees the letter. Student loan is an independent radio set (No · Plan 1 · Plan 2 · Plan 4) plus a separate Postgraduate Loan tick, since a plan and a PG loan can run together. NI number is optional (no temporary number — payroll runs without one; entering it later sends E6) and locks masked once saved. The declaration tick is required before submit. No P45 upload exists anywhere in the app. 8/11 two referees with name · relationship · phone · email, phone and email both mandatory, no relatives, tutors/lecturers/coaches/volunteering supervisors accepted; not reviewed or verified by anyone — stored and shown on the profile only (§2.10).
