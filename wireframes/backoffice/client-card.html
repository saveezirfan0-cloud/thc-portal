Behaviour notes. Four blocks (§9.7). 1 General info — contact · phone · average margin; Edit opens every client field (name, contact full name, contact phone, staff contact point, allocation emails, break policy, buffer policy); there is no Delete. 2 Rate card — roles are added explicitly via "+ Add role", a dropdown of the Roles catalog (§9.8); a role missing from the catalog must be created there first; per role the manager sets the charge rate and builds the dress-code list ("Add a dress code" + "+ Add", repeatable); final pay (base × 1.1207) and margin are calculated alongside; editing stays open all year. This list is the predefined set offered on the event form's dress-code field; the event-level "Other" is not saved back (§3.2). 3 Qualified staff — grouped by role with a per-role counter ("Waiting Staff · 34 qualified") showing the depth of the first-choice pool; photo · name · role(s) here · rating · show-rate · how granted (manual by whom / automatically from a named event) · date; "+ Add staff" bulk-adds from the directory; per row Remove or Do not return (§9.6). 4 Events · this client — event · PO (read-only) · date (derived window) · venue · roles · margin; click opens the event page (§3.2).
