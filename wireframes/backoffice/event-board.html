Behaviour notes. One block per role, collapsible on its heading, ordered by start time so the board reads like the running order of the day; header "N confirmed · M invited · K open of H" counts ONLY confirmed, followed by the role's own window (dual-zone for a non-UK viewer, §1.8), dress code from the client's rate card and pay/charge (§3.3). Header carries title, client, venue, date, derived event window, PO NUMBER chip, status pill, Break/Buffer policy checkmarks and actions Edit · Duplicate · Send allocation sheet · Download · Cancel event (§3.2, §11.4). Sections: Confirmed → Invited · awaiting response → Potential pool (ranked, search, sort/filter by application status, "Qualified — client · role" chip, "Applied" marker with relative time, Invite per row) → Unavailable with reasons blocked-compliance / booked-elsewhere / hours limit reached / rejected (self-cancelled, RULE-04) / do not return; wrong-role never appears (§3.3, §6, §9.6). Invited and Potential pool exist only while a role has open or invited slots; hidden entirely when a role is fully confirmed and stable, and they reappear on an Ongoing event when a shortfall re-opens (§3.3). No-shows stay inside Confirmed with a "No show" badge and "Get back" (reclassifies to Late from the moment pressed); auto No-show at start + 30 min; manual button live from shift start to 2 weeks after; payroll-export warning verbatim from §3.3. Manager has Withdraw only — the worker confirms in the app (§3.3, §3.5). Auto-assign is a purple switch, default ON, per event and per role; hourly rounds at :17 in score order, qualified wave first (RULE-17), hours limit and compliance are hard gates, 2-hour gap rule for different venues; same-day escalation every 10 minutes within 3 miles (§3.4). Score = 30/25/25/10/10 with per-factor hover breakdown and legend (§6). Cancel event needs a reason and lists its consequences (§3.3). Completed events offer Send / Download sign-out timesheet, one PDF per event (§11.3). Removed workers stay as "Deleted account #id" so the headcount isn't skewed (§1.7).
